# Research memory

Research memory answers: what was tried, what was found, what failed, why, on which data, under which assumptions, what was not tested, what was selected, rejected, redundant, falsified, or replicated.

Failed work is first-class. Deleting a loser is an integrity FAIL (`candidate_history_deleted`). Historical evidence and claims are immutable. New conclusions supersede old ones via `SUPERSEDES` edges; the old claim stays frozen.
