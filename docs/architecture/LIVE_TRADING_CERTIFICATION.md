# Live Trading Certification

**Version:** 2.8.0  
**Package:** `quantlab.release`  
**Desktop:** Certification & Promotion Lab (`promote`)

Certification proves readiness against defined criteria. It does not create permission to trade.

```text
CERTIFIED ≠ LIVE_ENABLED ≠ BROKER_CONNECTED
LIVE_TRADING=false
```

State machine ends at `RELEASE_ELIGIBLE`. There is no `LIVE` state. Restricted live is not implemented. Safety cannot be waived. AI cannot certify.
