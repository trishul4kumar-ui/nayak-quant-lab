# Stationarity

**Version:** 2.3.0

ADF uses MacKinnon’s large-sample 5% critical value (−2.86, constant, no trend). KPSS uses 0.463. These are tabulated diagnostics, not certified p-values. Phillips-Perron is an interface that returns `NOT_TESTED` until a certified implementation is sourced. Windows are PIT: no future stationarity selection.
