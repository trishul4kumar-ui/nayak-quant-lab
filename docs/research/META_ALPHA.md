# Meta-alpha

```
META-ALPHA ≠ ALPHA
```

A meta-alpha is a model of component scores plus PIT component behaviour. Base alphas and models keep independent identities and versions.

Linear meta-alpha reuses Prompt 11 OLS / ridge / elastic-net. Rank-sum `rank(A)+rank(B)+…` is a baseline, not proof of alpha.

Weights and coefficients are fit only on historical windows whose labels are available at T.
