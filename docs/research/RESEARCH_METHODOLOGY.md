# Research methodology

QUANT LAB records scientific work as frozen hypotheses, candidate families, and ledger rows.

```
DEFINE → FREEZE → SEARCH → TEST → COMPARE → FALSIFY
  → VALIDATE → MULTIPLE TESTING → REPLICATE → REPORT → GATE → LEDGER
```

Search broadly. Record everything. Control degrees of freedom. Falsify aggressively. Validate out of sample. Account for multiple testing. Replicate. Only then consider promotion — and only via the Prompt 05 gate.

A strategy that fails is useful. Synthetic confirmation is not NSE alpha.
