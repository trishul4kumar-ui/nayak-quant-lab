# Alpha discovery validation

Discovery survivors are not research candidates.

Validation for a discovered expression:

1. Train IC used for search selection
2. Validation IC and sign-reversal / label-permutation falsification
3. Walk-forward windows on the train fold only
4. Holdout IC recorded once (`NOT_TESTED` as selection evidence)
5. Family BH correction via Prompt 14/05
6. Prompt 05 gate — synthetic remains `WARN` / cannot promote

A failed OOS expression is a successful falsification result. Failed candidates stay in the archive.
