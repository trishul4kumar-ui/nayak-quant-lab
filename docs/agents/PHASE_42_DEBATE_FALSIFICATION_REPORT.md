# Phase 42 — Adversarial debate and falsification

Started after Phase 41's published CI acceptance for `794b880`. Implementation is
undergoing release checks; Phase 43 must not begin until those gates pass.

Added strict critique/rebuttal drafts, a fixed 42-v1 protocol, same-boundary session
creation, parent-bound role contexts, permanent run claims and immutable transcripts
on the existing migrated SQLite control plane. There is one critique each and at
most one optional rebuttal each, no recursive conversation or arbitrary execution.
Initial memos are never edited or regenerated by the debate worker.

Shared tool evidence has exact request/result lineage. Unsupported prose, severity
and raw confidence have no quantitative authority. Falsification routes retain
NOT_TESTED unless the exact named canonical check exists; unbound adapters are
explicitly unavailable. Same-source descriptors cannot become predictive PASS.

Native Debate Arena includes blocking feedback, cancellable background operation,
immutable transcript selection, resizable transcript/check panels and working
evidence navigation. The local opt-in Three.js scene adds a shared evidence graph,
support/contradiction/reference/request edges, actual agent states and a clickable
neutral center, with a mandatory native fallback. DTOs expose no model provider,
broker token, tool methods or order APIs. Adjudication is explicitly NOT_BUILT.
