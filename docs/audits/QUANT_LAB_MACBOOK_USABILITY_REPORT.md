# MacBook usability report — 2026-10-04

The desktop shell now treats 1024×640 as compact desktop, not as an incomplete
wide layout. At compact width the sidebar becomes an icon rail without changing
the saved user preference, the command search remains full-width, primary mode
controls remain accessible, KPI cards wrap, and terminal panels use one column.

At 1280×800, page chrome, tables, and primary controls remain readable without
an external monitor. At 1512×982, the workstation restores a denser expanded
sidebar and four-card dashboard layout. Dense evidence surfaces keep local
horizontal scrolling available instead of hiding data or crushing columns.

The reset command is available from the NAYAK QUANT LAB menu and only resets UI
workspace state.
